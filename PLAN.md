# MCP Apps Development Plan

## Overview

This project uses the **`create-mcp-app`** skill from the official MCP Apps extension. The skill provides architecture guidance, best practices, and working examples that an AI coding agent uses to generate complete MCP App projects.

---

## What is the `create-mcp-app` Skill?

The `create-mcp-app` skill is an agent skill that teaches AI coding assistants how to scaffold MCP Apps. When installed, your agent can:

- Generate complete MCP App projects from natural language descriptions
- Apply best practices for security, theming, and communication
- Create properly structured servers with UI resources and tool linking
- Produce working examples ready to run

---

## Installation

### Option 1: Claude Code Plugin (Recommended)

```bash
/plugin marketplace add modelcontextprotocol/ext-apps
/plugin install mcp-apps@modelcontextprotocol-ext-apps
```

### Option 2: Manual Installation (Global Skill)

```bash
# Clone the ext-apps repository
git clone https://github.com/modelcontextprotocol/ext-apps.git

# Copy the skill to your global Claude skills directory
cp -r ext-apps/plugins/mcp-apps/skills/create-mcp-app ~/.claude/skills/create-mcp-app
```

### Verify Installation

Ask your agent:

> "What skills do you have access to?"

You should see `create-mcp-app` listed as an available skill.

## Usage

### Creating an App

Simply describe what you want to your AI coding agent:

```
Create an MCP App that displays a color picker
```

The agent will:
1. Recognize the `create-mcp-app` skill is relevant
2. Load its instructions and examples
3. Scaffold a complete project with:
   - MCP server configuration
   - UI resource declarations
   - Tool definitions with UI linking
   - HTML/JS app code
   - Build configuration

### Running Your App

After the agent generates your project:

```bash
npm install && npm run build && npm run serve
```

Then configure your MCP client (e.g., Claude Desktop) to connect to the server.

## Architecture (Generated by Skill)

The skill generates projects following this structure:

```
my-mcp-app/
├── src/
│   ├── server/
│   │   └── index.ts       # MCP server with tools and UI resources
│   └── app/
│       ├── index.html     # App entry point
│       ├── app.ts         # App logic and MCP bridge
│       └── styles.css     # Themed styles using CSS variables
├── package.json
├── tsconfig.json
└── README.md
```

### Key Components

**Server** (`src/server/index.ts`):
- Declares UI resources with `ui://` scheme
- Defines tools with `_meta.ui` linking to resources
- Handles tool calls and returns data to the UI

**App** (`src/app/`):
- HTML5 document with MCP App profile
- Uses CSS variables for host theme integration
- Communicates via postMessage JSON-RPC bridge

## Best Practices (Built into Skill)

The skill automatically applies these best practices:

### Security
- Minimal CSP domain declarations
- Sandboxed iframe compliance
- Input validation patterns

### Theming
- CSS variables for host integration (`--mcp-background`, `--mcp-foreground`, etc.)
- Respects `prefersBorder` setting

### Communication
- Proper JSON-RPC message structure
- Error handling patterns
- Request/response correlation

### Fallbacks
- Text-only fallback for non-UI hosts
- Graceful degradation patterns
